# 청약 인식 댓글 분류 기준 (classify_comments.py 가 이 파일을 읽어 프롬프트에 넣는다)
# 분석 영상: 크랩, 「청약통장 다들 왜 깨고 있을까?」 https://www.youtube.com/watch?v=g4h29mJufpc
# ev-run.py 가 ev-index.txt 를 읽는 방식과 같다. 기준을 바꾸려면 이 파일만 고치면 된다.

[stance] 태도 — 하나만 선택
N = 청약 제도·청약통장에 부정적이거나 회의적 ("쓸모없다", "당첨돼도 못 산다", "해지했다")
M = 양가적·중립적이거나 정보 제공 ("고민 중", "소득공제용으로만 둔다", 질문)
P = 긍정적이거나 유지를 권장 ("깨지 마라", "임대 가점에 쓸모 있다", "당첨돼서 집 샀다")
X = 청약에 대한 판단이 없음 (정치 구호, 세대 비난, 감탄사, 영상과 무관한 잡담)

[topics] 관심사 — 해당하는 것을 모두 선택, 없으면 빈 목록
A = 분양가·집값 부담 (분양가가 너무 비쌈, 계약금·잔금 마련 불가, 가격 수준 언급)
B = 대출규제·자금조달 (대출 한도·LTV, 대출이 막힘, 이자 부담)
C = 가점·당첨확률 (가점 부족, 경쟁률, 당첨이 안 됨)
D = 제도 불공정 (1인가구·미혼 불리, 소득·자산 요건 모순, 특별공급, 금수저·부모 지원)
E = 대체 투자·낮은 금리 (청약 대신 주식·ETF·적금, 통장 금리가 낮음, 돈이 묶임)
F = 정부·정치·세대 불신 (정부·정당·대통령 비판, 세대 갈등, "정책은 또 바뀐다")
G = 부가 기능 (LH·SH 임대주택 가점, 디딤돌 등 대출 금리우대, 소득공제)
H = 수도권 집중·지방·인구 (서울 쏠림, 지방 미분양, 인구 감소, 빈집)
I = 신축 품질·하자 (부실공사, 순살 아파트, 하자)

[outlook] 집값 전망 — 하나만 선택
U = 상승 (앞으로 오른다, 계속 오르고 있다)
D = 하락 (떨어질 것이다, 폭락, 빈집이 넘칠 것)
0 = 언급 없음 (가격이 "비싸다"는 현재 수준 언급만 있으면 0)

[action] 청약통장 행동 — 하나만 선택
H = 해지했거나 해지할 예정
K = 유지하고 있거나 유지를 권함
0 = 언급 없음
